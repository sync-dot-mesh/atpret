# Brainstorms

A dated log of design decisions, mistakes, and reasoning for `atpret`
— same convention as `sync-dot-mesh`'s `.github` repo and
`argenv-opencommons/argenv`. Each entry is a record of what was
decided and why, including the wrong turns, not just the clean
successes.

Naming, language, and dependency decisions that predate this repo's
own existence live in
[`sync-dot-mesh/.github`'s `brainstorms/argenv-atpret/`](https://github.com/sync-dot-mesh/.github/tree/main/brainstorms/argenv-atpret)
instead — that folder holds everything spanning `atpret` and `argenv`
together; this one holds `atpret`-only implementation detail from
here on.
